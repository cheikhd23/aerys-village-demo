# Aerys Village — Website Concept

Premium bilingual hospitality website concept for Aerys Village in Somone, Senegal.

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

## Stack

- React
- Vite
- Tailwind CSS

## Demo notice

This is an independent proposal website, not the official Aerys Village website. Public Instagram and Booking.com images are used as temporary demonstration placeholders only. Replace them with client-approved, licensed assets before an official launch.
